Jack Chesney Portfolio Update
============================

How to apply
------------
1. Extract this ZIP into the existing portfolio folder.
2. Replace matching HTML and CSS files.
3. Keep all existing website assets (logos, dashboard images and PDFs) that are already in that folder.

Included changes
----------------
- Added project-fabric-platform.html as a separate case study.
- Featured projects are now:
  1. Microsoft Fabric Data Platform
  2. Executive Financial Dashboard
  3. End-to-End Fabric Quote Analytics
- Added the Fabric platform project to the Projects page while preserving the existing quote analytics project.
- Kept the central story focused on building a reporting environment from the ground up.
- Used CargoWise shipments as the main source-to-reporting example while clarifying that the wider CargoWise database is complex.
- Added expandable, sanitised SQL and Python examples.
- Added Python to the project-card tools and the case-study Tools & Skills section.

- Added SQL immediately after ETL in every footer.
